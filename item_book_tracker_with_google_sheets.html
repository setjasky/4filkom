Google Sheets Database Sync

How to Setup Free Google Sheets Database (2 mins):

  1. Open a new Google Sheet.
  2. Click Extensions > Apps Script.
  3. Delete any existing code and paste the Google Apps Script code below.
  4. Click Deploy > New Deployment > Select type: Web app.
  5. Set Who has access to "Anyone" and click Deploy.
  6. Copy the generated Web App URL and paste it into the field above.
