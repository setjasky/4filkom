Add Project Guide

Instructions for adding new pages to your sandbox

To register a new HTML page in this grid, add the following code structure into index.html inside #projectsGrid:

<a href="your_page.html" 
   class="glass-tile accent-blue group min-h-[220px]" 
   data-title="Your App Name" 
   data-category="Web App"
   data-desc="Short description">
  <div class="tile-inner-layout">
    <!-- Tile Header & Content -->
  </div>
</a>
Available Accent Colors: accent-blue, accent-emerald, accent-purple, accent-amber, accent-cyan, accent-pink, accent-rose, accent-orange
