How to Install on Android

Add TikTok Vault to your home screen in 3 easy steps

Method 1: Direct Install Button

If visible, tap the install button directly.

Method 2: Google Chrome / Brave / Edge
  1. 1
    Open Browser Menu

    Tap the three vertical dots ⋮ in the top-right corner of Chrome.

  2. 2
    Select "Add to Home screen"

    Tap on "Add to Home screen" or "Install app" from the menu options.

  3. 3
    Confirm Installation

    Tap "Add" or "Install" in the popup prompt.

Method 3: Samsung Internet
  1. 1
    Open Menu

    Tap the menu icon ≡ in the bottom-right corner.

  2. 2
    Add Page To

    Tap "Add page to" and select "Home screen".

Once installed, TikTok Vault launches full-screen without address bars, saves offline content, and runs seamlessly like a native Android app!
